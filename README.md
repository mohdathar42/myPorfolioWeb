# Athar React Portfolio

A modern responsive portfolio built with React.js and Vite.

## Requirements

- Node.js 18+
- npm

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Customize

Edit `src/App.jsx` to update:
- Name
- Email
- GitHub
- LinkedIn
- Skills
- Projects
- Experience
- Education
